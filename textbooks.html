Instructions

  • Active Sign-Outs: Type student name, teacher, and location.
  • Returns: Delete the student's name from the row to clear it.
  • Missing Books: Type "missing" in the location column. It will turn RED and prompt you to add the student to the Liabilities Ledger.
  • Repairs: Type "Binding" in the location. It will turn PINK.
  • Teacher Holds: Type "teacher" in the location. It will turn GREEN.
  • Before Distributing: Check the Liabilities Ledger tab to ensure the student has no outstanding fines.
